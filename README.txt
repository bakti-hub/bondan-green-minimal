BONDAN GREEN — MINIMAL VERSION

File:
- index.html
- styles.css
- script.js

Pemasangan di GitHub Pages:
1. Backup repository.
2. Di branch master, buka ROOT repository (bukan folder dist).
3. Ganti index.html dan upload styles.css serta script.js ke root.
4. Jangan hapus file CNAME dan jangan ubah Settings > Pages.
5. Commit changes lalu tunggu GitHub Pages selesai publish.

Versi ini menggunakan desain minimalis editorial: warna terbatas, tanpa efek glow/gradient dekoratif, kartu lebih sederhana, dan ruang kosong lebih teratur. Tidak menggunakan Bootstrap/Start Bootstrap. Foto Unsplash dan Google Fonts masih eksternal; ganti foto contoh dengan foto asli prototipe untuk identitas yang lebih autentik.
